OPEN-SOURCE AI INFRASTRUCTURE

What is SUAY?

SUAY is an open-source local AI resource-sharing project. It combines an organization access and inference-gateway pilot with a separate experiment for distributed LLM inference over a trusted LAN using Petals.

For developers and IT teams evaluating on-premise AI, the goal is to test existing CPU/GPU resources before investing in more infrastructure. Hardware support, model coverage, electricity and maintenance costs still need to be measured.

Maintained by campong and contributors. Code: MIT. Read the architecture

PROJECT FACTS / FAQ

Questions about local AI and shared compute

What is SUAY?

SUAY is an open-source project for local AI resource sharing. It provides an organization access and inference-gateway pilot, alongside a separate experimental Petals LAN compute pool.

Can old computers run AI together?

Some older machines can contribute if their supported runtime, memory and network meet the workload requirements. SUAY does not guarantee that every old device can run a model or improve performance.

Does SUAY combine the RAM of every device?

The Petals experiment distributes supported model blocks across workers. It is not a general shared-memory system. A request-routing inference pool and splitting one large model are different approaches.

What works today?

The pilot includes user roles, zone and selected-node visibility, expiring API keys, request budgets, audit events and an inference proxy to an approved backend. Worker commands remain pending until native transport is implemented.

Which operating systems are supported?

The Python control-plane pilot can be evaluated where its dependencies run. The compute pilot needs a verified Petals environment. Native Windows, macOS and Linux service installers are planned; Android compute is not a released feature.

Is SUAY free for business use?

Original SUAY code is MIT licensed and can be used commercially under that license. Model weights and dependencies have separate terms; BLOOM uses BigScience RAIL. Review each model before organizational use.

Can developers use SUAY through an API?

Yes. An operator can configure an approved inference backend and issue scoped API keys for non-streaming chat completions. Budgets count accepted requests; reported model-token usage is tracked separately.

Is SUAY ready for production?

SUAY is an early pilot. Native worker identity, SSO/MFA, signed deployment and automatic model migration are not complete. Evaluate it on a trusted test network before considering production.

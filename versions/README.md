# Choose a SUAY version

| Directory | Role | Status |
| --- | --- | --- |
| [Python](python/) | Organization gateway/dashboard, separate Petals LAN pilot, independent public-site analytics | Pilot / experimental |
| [Rust](rust/) | Local hardware snapshots, memory admission and owned-backend process supervision | Experimental |

These directories have different roles; Rust is not a complete replacement for
the Python implementation. Read each directory's instructions and limitations.
Neither folder is a prebuilt installer or a promise of compatibility with every OS.

The repository path is **versions/**, not `version/`.

SUAY adalah proyek sumber terbuka untuk berbagi sumber daya komputasi bagi AI lokal di organisasi. Tersedia pengelolaan akses, gateway inferensi percontohan, dan eksperimen Petals LAN yang terpisah.

Lihat kode dan beri Star ↗

Bagaimana SUAY bekerja?

Admin menetapkan model dan backend yang disetujui. Pengembang mengirim permintaan melalui gateway memakai kunci API. Eksperimen Petals membagi blok model di LAN tepercaya dan belum terhubung otomatis ke gateway.

Pilih versi sesuai kebutuhan

Versi Python menyediakan control plane dan uji coba Petals. Versi Rust mengelola proses lokal dan anggaran memori, bukan menulis ulang Petals. Installer layanan native dan fleet transport belum tersedia.

Pertanyaan umum

Apakah organisasi boleh memakai SUAY secara gratis?

Kode asli SUAY berlisensi MIT. Model dan dependensi memiliki ketentuan terpisah yang perlu ditinjau sebelum penggunaan komersial.

Bisakah setiap komputer lama membantu menjalankan AI?

Tidak ada jaminan. Kebutuhan runtime, memori, dan jaringan bergantung pada beban kerja. Ilustrasi perangkat bukan sertifikasi kompatibilitas.

Apakah siap untuk produksi?

Masih tahap percontohan. Perangkat keras dan keamanan harus diuji. Migrasi model otomatis dan integrasi fleet belum lengkap.

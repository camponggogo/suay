01 / THE OPPORTUNITY

Big ambition.
Real-world budgets.

AI shouldn’t stop at
“we don’t have the budget.”

Cloud bills add up. New GPUs take approval. Meanwhile, useful compute sits across the organization, waiting for the next task.

SUAY explores a practical alternative: share local AI workloads, make resource access visible, and help teams build on the capacity they already have.

เพิ่มโอกาสให้ทีมได้ใช้ AI จากทรัพยากรที่องค์กรมีอยู่แล้ว เริ่มเล็ก วัดผลจริง แล้วขยายไปด้วยกัน

01

Start with what you own.

Evaluate existing CPU/GPU capacity before adding infrastructure. Hardware, network and workload still determine what is feasible.

02

Keep the boundary local.

Design for organization-controlled inference. The current Petals pilot needs a trusted network; stronger worker identity is on the roadmap.

03

Give builders a way in.

Scoped developer keys, zone access and usage visibility bring local AI closer to everyday engineering workflows.

03 / BUILT IN THE OPEN

Honest progress.
Open possibilities.

A second life for older hardware.
An early project, with a clear direction.
Here is what you can work with today.

PILOT AVAILABLE

Organization access

Admin sign-in, first-login password change, zone and selected-agent permissions, revocable API keys and audit events.

01
PILOT AVAILABLE

Developer API gateway

Scoped keys, expiry and request budgets for a configured inference backend. Model token usage is reported separately.

02
EXPERIMENTAL

Distributed inference

A Petals LAN prototype for sharing model blocks. Requires supported models, complete block coverage and real hardware validation.

03
ROADMAP

Native services & fleet control

Windows, macOS and Linux services; authenticated worker transport; safe model rollouts. Android begins with a gateway client.

04

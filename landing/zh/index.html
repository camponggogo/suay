SUAY 是面向组织内部本地 AI 的开源资源共享项目，提供访问管理和推理网关试验版，以及独立的 Petals 局域网实验。

SUAY 如何工作？

管理员配置获批的模型和后端，开发者使用 API 密钥通过网关发起请求。Petals 实验在可信局域网中分配模型块，目前尚未与网关自动集成。

START HERE / MACHINE BY MACHINE

Install SUAY: gateway, workers and client

Choose a path first. A runs the organization gateway. B runs the separate Petals compute pilot: start agents before the terminal client. Rust is optional local supervision.

Read the full machine-by-machine guide (Thai) ↗

PATH A / ONE MANAGEMENT MACHINE

1. Organization gateway

  1. Clone SUAY; create a separate control environment.
  2. Install control requirements and start uvicorn on this machine.
  3. Open localhost:8090, change the initial password, then configure your own inference backend before issuing inference keys.
Launch command after installation
.venv-control/bin/python -m uvicorn control.app:create_app --factory --app-dir versions/python --host 127.0.0.1 --port 8090

Linux/macOS launch after installation. The gateway has no bundled model. It does not automatically connect to the Petals pool.

Gateway installation guide ↗

PATH B / EACH COMPUTE MACHINE

2. Coordinator + workers

  1. On supported Linux hosts, create a Petals Python 3.10 environment and install agent requirements.
  2. Set the same model and broadcast settings, and each machine’s own LAN IP; start the same agent file on every compute host.
  3. The lowest active IPv4 becomes coordinator and also serves blocks. Check agent status at port 8080 and verify model block coverage.
Launch command after installation
.venv-petals-agent/bin/python versions/python/compute/agent/auto_agent.py

Experimental trusted-LAN pilot. No separate coordinator program, manual role switch or universal device certification.

Coordinator and worker guide ↗

PATH B / USER MACHINE / AFTER AGENTS

3. Terminal prompt client

  1. Wait for a ready agent with nonempty bootstrap peers.
  2. Install client requirements in a separate Petals Python 3.10 environment.
  3. Use the agent’s LAN IP and port 8080. Wait for the terminal prompt; type /quit to exit.
Launch command after installation
.venv-petals-client/bin/python versions/python/compute/client/app.py --coordinator http://AGENT_IP:8080 --max-new-tokens 32

Replace AGENT_IP. This uses Petals P2P, not the 8090 gateway. The client is not a browser chat; the GIF’s AI Agent UI is illustrative.

Client installation guide ↗

OPTIONAL / ONE LOCAL BACKEND

4. Rust resource supervisor

  1. Install Rust 1.88+ and a compatible linker. Inspect hardware with the status command.
  2. Configure an existing absolute backend executable and appropriate memory budgets.
  3. Validate the config before supervision. Do not start a duplicate backend separately.
Launch command after installation
cargo run --manifest-path versions/rust/Cargo.toml --locked -- status

Not required for A or B. Rust does not replace the Python coordinator, workers or client.

常见问题

企业可以免费使用 SUAY 吗？

SUAY 原始代码采用 MIT 许可证。模型和依赖项具有独立条款，商业使用前应逐项核查。

所有旧电脑都可以参与 AI 计算吗？

不能保证。实际任务决定运行时、内存和网络要求。设备插图不代表硬件兼容性认证。

是否已经适合生产环境？

目前仍是试验项目。使用前需要验证硬件和安全性。自动模型迁移与设备集群集成尚未完成。

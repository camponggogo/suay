คอมพิวเตอร์ในออฟฟิศคุณ
คือเครื่องที่คุณต้องการอยู่แล้ว

PASADHI รวม PC, เซิร์ฟเวอร์ และโน้ตบุ๊กที่องค์กรมีอยู่ ให้เป็นพื้นที่ประมวลผลเดียว รัน AI Agent บนเครื่องเหล่านั้น ข้อมูลไม่ออกจากตึก และได้เครดิตเมื่อปล่อยเครื่องที่ว่างให้ส่วนรวม

ดาวน์โหลด · ฟรี ดูว่าแชร์แล้วได้เท่าไร

ฟรี จนกว่าเครือข่ายจะเต็ม

ระหว่างที่ PASADHI กำลังสร้าง pool ทุกอย่างที่รันบนระบบนี้ ฟรี สำหรับคนที่แชร์ด้วย

  • แชร์ 20–30 % ของเครื่อง → ใช้ AI Agent ฟรี
  • ไม่ต้องผูกบัตร ไม่มีทดลองจำกัดเวลา ไม่คิดราย token
  • เปิดให้เช่าจริงเมื่อ pool มีกำลังเหลือเท่านั้น

ลำดับการเปิดบริการ

ฟรีก่อน เช่าที่สอง On-prem ตลอด

เราจะไม่ขายอะไรจนกว่าจะมีกำลังเหลือ ลำดับนี้ตั้งใจ: สร้าง pool ด้วยคนที่แชร์ แล้วค่อยปล่อยส่วนเกินให้เช่า และเปิดให้ซื้อซอฟต์แวร์ขาดได้เสมอ

เปิดใช้แล้ว

1 · แชร์แล้วใช้ฟรี

ติดตั้งแอป เลือก % ที่จะแชร์ แล้วใช้งานได้ทันที เครดิตสะสมไว้หักค่าใช้จ่ายในอนาคต

เปิดเมื่อมีกำลัง

2 · เช่ารายเดือน / รายปี

เมื่อ pool มีกำลังเหลือ ให้เช่าเป็นรายเดือนหรือรายปี ไม่ต้องซื้อ GPU และไม่มีค่า egress

มีตลอด

3 · On-prem licence

ซื้อซอฟต์แวร์ไปรันในองค์กรเอง ใช้เฉพาะภายใน ข้อมูลไม่ออกนอกเครือข่าย

สินค้าตามลำดับการออก

AI Agent → Cloud → VPS

ทุกตัวคือพื้นที่ประมวลผลเดียวกัน แต่หน้าตาต่างกัน — เราจะประกาศเมื่อใช้งานได้จริงเท่านั้น

ตัวแรก

AI Agent

เอเจนต์ที่อ่านเอกสาร ตอบคำถาม และเรียกเครื่องมือได้ ทำงานบนเครื่องของคุณเอง โมเดลของคุณเอง และข้อมูลไม่ออกจากองค์กร

  • รันบน pool หรือเครื่องเดียว
  • มี token ประจำเครื่อง
  • เห็นการใช้รายแผนก
ถัดไป

Cloud

Control plane แบบโฮสต์ให้ สำหรับองค์กรที่ไม่อยากดูแล coordinator เอง — แอปเดิม โควตาเดิม แต่มีคนดูแลให้

  • group id, join token, โควตา
  • รายเดือน / รายปี
  • เลือกที่เก็บข้อมูลได้
หลังจากนั้น

VPS

ขายกำลังประมวลผลเป็นเครื่องเสมือนขนาดเล็ก: จำนวน core, RAM, ดิสก์คงที่ คิดรายเดือน เหมาะกับบริการที่ต้องการ "เครื่อง" ไม่ใช่ "โมเดล"

  • ขนาดอิงจากกำลังที่วัดได้
  • snapshot และย้ายเครื่องได้
  • เครือข่ายแยกตาม group

ดาวน์โหลด

แอปเดียว Windows, Linux, macOS, Android

แอปจะตรวจสเปกเครื่อง เลือก role เอง (coordinator / worker / client) และแสดงสไลเดอร์แชร์พร้อมรายได้ประมาณการ

Windows.msi · x64 Linux.deb · AppImage macOS.dmg · Apple silicon & Intel Android.apk · foreground service

ปุ่มจะเปิดใช้เมื่อ build พร้อม — ระหว่างนี้รันจากซอร์สได้ด้วย python pasadhi/app/service.py

คำถามที่พบบ่อย

สิ่งที่คนถามก่อนติดตั้ง

ฟรีจริงไหม

จริง ระหว่างที่ pool ยังสร้างไม่เต็ม: แชร์ 20–30 % ของเครื่อง แล้วใช้ AI Agent ฟรี การเช่าจะเริ่มเมื่อเครือข่ายมีกำลังเหลือ

ไฟล์ของฉันเป็นอย่างไร

เอเจนต์รันบนเครื่องคุณ โหมด on-prem ไม่มีข้อมูลออกนอกเครือข่าย โหมดแชร์ส่งเฉพาะ tile งานที่เข้ารหัส และเครื่องที่รับงานไม่เห็นไฟล์คุณ

ใช้เครื่องมากแค่ไหน

ตามที่ตั้งไว้ — สไลเดอร์จำกัด CPU, GPU, RAM, ดิสก์ และเครือข่าย ค่าเริ่มต้น 20–30 % เครื่องยังใช้งานปกติ

ต้องมี GPU ไหม

ไม่ต้อง pool แบบ CPU ก็ทำงานได้ การ์ดเล็กอย่าง GTX 1050 ทำให้เร็วขึ้นประมาณ 22 เท่าในงานเดียวกัน

หยุดแชร์ได้ไหม

ได้ทุกเมื่อจากหน้าต่างเดิม worker จะหยุดภายในรอบจัดคิวถัดไป และเครดิตยังอยู่

On-prem ราคาเท่าไร

เริ่ม 18,900 บาท/กลุ่ม/เดือน ไม่จำกัดเครื่อง รวมแผนก · merge หลาย licence คิดตามองค์กร
